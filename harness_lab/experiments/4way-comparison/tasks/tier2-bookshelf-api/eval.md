# Bookshelf API 채점 기준

## 채점 공식
- 기본 점수 = (기본 테스트 통과 / 기본 테스트 전체) × 70
- 히든 점수 = (히든 테스트 통과 / 히든 테스트 전체) × 30
- 총점 = 기본 + 히든 (100점 만점)

## 등급 기준
| 등급 | 점수 범위 | 기준 |
|------|----------|------|
| S | 95-100 | 히든 테스트 포함 거의 완벽 |
| A | 85-94 | 기본 기능 완벽 + 히든 대부분 통과 |
| B | 70-84 | 핵심 기능 동작, 일부 에지 케이스 실패 |
| C | 50-69 | 기본 CRUD 동작, 인증/권한 부분 실패 |
| F | 0-49 | 핵심 기능 미구현 또는 대량 실패 |

## 기본 테스트 영역 (~60개)
| 영역 | 테스트 수 | 배점 비율 |
|------|----------|----------|
| 인증 (Auth) | 12 | ~14% |
| 책 CRUD | 12 | ~14% |
| 서재 관리 | 12 | ~14% |
| 검색/필터링 | 12 | ~14% |
| 유효성 검사 | 12 | ~14% |

## 히든 테스트 영역 (~30개)
| 영역 | 테스트 수 | 배점 비율 |
|------|----------|----------|
| 인증 에지 케이스 | 8 | ~8% |
| 입력 에지 케이스 | 8 | ~8% |
| 통합 시나리오 | 14 | ~14% |

## 감점 요인 (자동 감점 아님, 분석용)
- 보안 취약점 발견 시 별도 기록
- 코드 품질 이슈 별도 기록
- 에러 핸들링 일관성 별도 기록
